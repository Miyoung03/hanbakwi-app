# 한바퀴 · 나의 시간 기록

하루 목표를 한 바퀴씩 채워 가는 개인 시간 기록 웹앱(PWA)이에요. 서버 없이 파일 몇 개로 돌아가고, 기록은 모두 내 기기 안에만 저장돼요.

## 주요 기능

- **이번 달 누적시간**: 항목별 링을 한 원 안에 겹쳐 보여 줘요.
- **하루 목표**: 날짜마다 목표시간과 달성 시간을 입력해요. 요일별 반복 목표도 정할 수 있어요.
  - 달성은 파랑, 미달성은 빨강, 앞으로의 목표는 점선 링으로 표시돼요.
  - 달력형과 목록형 중에서 고를 수 있어요.
- **타이머**: 항목을 고르고 시작·종료하면 기록이 저장돼요.
- **봉사 기록**: 만난 사람(인상착의·장소·주소·기타·다음 만남), 사진 1장을 남겨요. 다시 만날 사람을 홈에서 모아 봐요.
- **기록 검색**: 메모, 인상착의, 장소, 주소로 모든 달을 찾아요.
- **통계**: 연간 합계, 월별 막대, 연간 잔디, 연속 기록, 일별 기록을 보여 줘요.
- **백업**: 전체 백업(JSON, 사진 포함)과 복원, CSV 내보내기를 할 수 있어요.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 전체(화면, 스타일, 동작) |
| `sw.js` | 오프라인 캐시 (서비스 워커) |
| `manifest.webmanifest` | 홈 화면 앱 정보 (이름, 아이콘) |
| `icon-180.png` `icon-192.png` `icon-512.png` | 앱 아이콘 |
| `logo-hanbakwi-en.png` | 헤더 로고 (영문 hanbakwi) |
| `logo-hanbakwi.png` | 한글 로고 (세 겹 링 + 한바퀴) |
| `fonts/` | 강원교육 모두 글꼴 (오프라인용) |

## GitHub Pages로 올리기

1. GitHub에서 새 저장소를 만들어요. 예: `hanbakwi`
2. 이 폴더를 그 저장소에 올려요.
   ```bash
   git remote add origin https://github.com/<내아이디>/hanbakwi.git
   git push -u origin main
   ```
3. 저장소 **Settings → Pages**에서 아래처럼 정하고 저장해요.
   - **Source:** `Deploy from a branch`
   - **Branch:** `main`, 폴더는 `/ (root)`
4. 1~2분 뒤 `https://<내아이디>.github.io/hanbakwi/` 주소가 생겨요.
5. 아이폰 **Safari**로 그 주소를 연 다음, **공유 → 홈 화면에 추가**를 누르면 앱처럼 쓸 수 있어요.

## 업데이트할 때

1. 파일을 고친 뒤 `index.html`, `sw.js`, `manifest.webmanifest`에 있는 버전 문자열(예: `20261016-r49-logo`)을 함께 올려요.
2. 그다음 다시 push해요.
3. 앱을 다시 열면 새 버전으로 바뀌어요.

## 데이터와 개인정보

- 기록은 브라우저의 기기 저장소(localStorage, 사진은 IndexedDB)에만 저장되고, 저장소(GitHub)에는 올라가지 않아요.
- Safari와 홈 화면 앱은 저장 공간이 따로일 수 있어요. 기기를 바꾸거나 앱을 다시 설치하기 전에 **설정 → 전체 백업**을 해 두세요.
- 아이폰 위젯 연동은 직접 설정한 Cloudflare Worker로 시간 합계만 보내요. 연결 주소와 보안키는 기기 안에만 저장돼요.
